# Комплекс веб-тренажёров «Системный анализ»

Интерактивные веб-приложения для дисциплины «Системный анализ». Два режима работы:

- **Офлайн** — открыть `index.html` в браузере, без сервера и интернета.
- **С сервером** — сторонний ризонер **OWL 2 RL** (`owlrl`) для вывода отношений в модуле 1.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Главная страница, карточки модулей |
| `module1_entropy.html` | Модуль 1 — оценка сложности структуры |
| `module2_concordance.html` | Модуль 2 — кластерная ранжировка |
| `module3_aggregation.html` | Модуль 3 — численное агрегирование |
| `app.py` | Бэкенд: ризонер OWL 2 RL (`owlrl`) + отдача статики |
| `requirements.txt` | Зависимости бэкенда |
| `run.sh` | Запуск сервера |
| `tests.js` | Автотесты (Node.js) |
| `vendor/` | Локальные библиотеки: Tailwind CSS, Vis.js |

## Запуск

### Офлайн

Открыть `index.html` двойным кликом. Нужен только браузер. Папку `vendor/` не удалять — там библиотеки.
В модуле 1 отношения выводит встроенный JS-ризонер (бейдж «встроенный (JS)»).

### С сервером (OWL 2 RL)

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
./run.sh                       # или: uvicorn app:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. В модуле 1 бейдж «OWL 2 RL · owlrl». Java не нужна.

### Тесты

```bash
node tests.js
```

32 проверки: энтропия (эталон 6.5), кластерная ранжировка (примеры из методички), Канделл W / χ², агрегирование, стресс-тест на случайных данных.

## Модуль 1 — «Оценка сложности системы»

### Что делает
Интерактивный редактор графа + редактор аксиом + вывод отношений `r1…r5` + расчёт энтропии `H(M,R)`.

### Граф (ABox)
- Добавление/удаление узлов; нумерация авто (минимальный свободный) или вручную.
- Добавление направленных связей `r1` перетаскиванием; узлы перетаскиваются мышью.
- Экспорт ABox в текстовый вид (мини-Turtle) с копированием в буфер.

### Аксиомы (TBox)
Текстовый редактор, мини-OWL. Поддерживаются конструкции:

```
:r2 owl:inverseOf :r1 .
:ancestorOf a owl:TransitiveProperty .
:r1 rdfs:subPropertyOf :ancestorOf .
:r3 owl:propertyChainAxiom ( :r1 :ancestorOf ) .
```

Проверка синтаксиса на лету (номер строки + подсказка формата). Ошибочные строки ризонер игнорирует. Кнопка «Сбросить» возвращает эталонный набор.

### Отношения
- `r1` — непосредственное управление (прямой предок);
- `r2` — непосредственное подчинение (обратное `r1`);
- `r3` — опосредованное управление (путь длины ≥ 2);
- `r4` — опосредованное подчинение (обратное `r3`);
- `r5` — соподчинённость (общий непосредственный начальник, без петель).

### Энтропия
Для узла `m_j` и отношения `r_i`: `l_ij` — число исходящих связей типа `r_i` от `m_j`.

- `P = l_ij / (n − 1)`, где `n` — число узлов;
- `H(m_j, r_i) = −P·log₂P` (принято `0·log₂0 = 0`);
- `H(M,R) = ΣΣ H(m_j, r_i)`, округление до 0.1;
- нормированная `h(M,R) = H / H_ref`, где `H_ref = c·n·k`, `c = 1/(e·ln2) ≈ 0.5307`, `k = 5`.

Эталон: стартовое дерево из примера → `H = 6.5`.

### Ризонер
Два взаимозаменяемых движка:
1. **Встроенный JS** — forward chaining, работает офлайн.
2. **Бэкенд `app.py`** — сторонний `owlrl` (OWL 2 RL). Если сервер не запущен — тихий откат на JS.

Диалект — подмножество **OWL 2 RL**: `owl:inverseOf`, `a owl:TransitiveProperty`, `owl:propertyChainAxiom`, `rdfs:subPropertyOf`. Полный **OWL 2 DL** (HermiT / Openllet) не подключён — это Java-движки.

## Модуль 2 — «Кластерная ранжировка»

### Что делает
Согласует мнения экспертов (2–12) в одну кластерную ранжировку, выделяет ядро противоречий, считает коэффициент Канделла W и χ².

### Ввод
Ранжировки «от меньшего приоритета к большему», через запятую. Равные приоритеты — в `{}`: `A, {B, C}, D`.

### Алгоритм ранжировки
1. Знаки: `s_e(i,j) = sign(r_e(j) − r_e(i))`.
2. Ядро противоречий `S` — пары с противоположными строгими мнениями (`∃e,f: s_e = +1, s_f = −1`); к ним добавляются единогласные равенства (`∀e: s_e = 0`).
3. Граф обязательных равенств `G0` → компоненты связности = первичные группы.
4. Турнир групп: `U → V`, если `∀e: r_e(a) ≤ r_e(b)` и `∃f: r_f(a) < r_f(b)`.
5. Ранг группы = `1 + входящая степень`.

### Вывод
- Кластерная ранжировка (ядро противоречий — блоки размера > 1, красным);
- матрица парных сравнений (подсветка пар с противоположными строгими мнениями);
- матрица рангов (связанные ранги — дробные) и суммы `R_j`;
- статистика.

### Статистика
- `R_j` — сумма рангов проекта `j` по всем экспертам;
- `S = Σ_j (R_j − m(n+1)/2)²`;
- `T_i = Σ_t (t³ − t)`, где `t` — размеры групп равенства эксперта `i`;
- `W = 12S / (m²(n³ − n) − m·ΣT_i)`;
- `χ² = m(n − 1)·W`; критические значения α = 0.05 / 0.01, df 1–20; автоматический вывод о согласованности.

## Модуль 3 — «Численное агрегирование»

### Что делает
Пошагово пересчитывает веса экспертов и групповые оценки до сходимости.

### Алгоритм
1. `x_ij = r_ij / Σ_j r_ij`.
2. `g_j = Σ_i w_i·x_ij`.
3. `ρ_i = Σ_j |x_ij − g_j|`.
4. `N = Σ_i 1/ρ_i`.
5. `w'_i = (1/ρ_i) / N`.

Остановка: `max|Δw| < ε` (ε настраивается). Есть пошаговый режим «Следующая итерация» и автопрогон.
Итог: веса экспертов и порядок проектов по возрастанию групповых оценок `g_j`.

## Бэкенд (`app.py`)

- `GET /health` — статус и профиль ризонера.
- `POST /reason` — тело `{"turtle": "...", "mode": "rl"}`, ответ `{"relations": {"r1": [[s,o], …], …}}`. Петли `r5(x,x)` отбрасываются.
- Статика: раздаёт HTML/JS/CSS. `tasks/`, `.git`, `.claude` и исходники не отдаются (404).

## Добавить новый модуль

В конце `index.html` найти массив `MODULES` и добавить объект:

```js
{ file: 'module4_new.html', title: 'Название', description: 'Кратко.', features: ['...'] }
```

Карточка появится на главной автоматически.

Алгоритм:

1. Канонические ранги → нормированные оценки xij = rij / Σj rij

2. Групповые оценки gj = Σi wi·xij

3. Расхождения ρi = Σj |xij − gj|

4. Нормирующая сумма N = Σi 1/ρi

5. Новые веса w′i = (1/ρi) / N
